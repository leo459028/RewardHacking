Safe MCP Gateway Rules 閘道器規則摘要

  • blocked / disabled server or tenant not allowed → denied (zero cost, no lease)
  • untrusted server → awaiting_approval (+0.20 risk, mcp_trust_gate)
  • external network with no_external_network=True → awaiting_approval (+0.15 risk, mcp_network_gate)
  • open MCP breaker → awaiting_approval (mcp_breaker_gate)
  • argument injection → denied + high incident; schema violation → denied (or approval when schema_enforcement=escalate)
  • Sensitive arguments are redacted to [REDACTED] before persistence.
