# Agent FinOps Core & Cost Accounting Reference

> **Module**: Agent FinOps Core (`v1.5.3`)
> **Schema Revision**: `202606010004` (Alembic Head)  
> **Reference Seed**: `app/seeds/model_pricing_seed.yaml`

This document details the architectural design, database schemas, active budget enforcement, context-aware pricing resolution, administration APIs, and YAML seed ingestion mechanics of the **Agent FinOps Core** engine.

---

## Core Mission & Functional Goals

1. **Immutable Cost Integrity**: Captures exact snapshots of model pricing within `cost_events.pricing_snapshot`. Future price revisions or catalog supersessions never mutate historical run accounting.
2. **Active Pre-Execution & Runtime Budget Enforcement**: Evaluates `run`, `tenant`, `workflow`, and `user` budget policies across `per_run`, `daily`, and `monthly` periods, triggering `block` (fail-closed `denied`), `require_approval` (`awaiting_approval`), `degrade_model` (`budget_model_degraded` fallback tier routing), or `warn_only`.
3. **Context-Aware Tiered Pricing & Savings Accounting**: Resolves `context_tier` (`<=128k`, `>128k`, `<=200k`, `>200k`), `minimum_billable_quantity`, `free_quota_Included`, and calculates `cache_savings` (cached input vs. standard input) and `batch_savings` (batch tier vs. standard tier).
4. **Standardized Pricing Seed & Stale Source Guardrail**: Parses official model rate cards from `app/seeds/model_pricing_seed.yaml` supporting dry-run validation, atomic batch applications, and stale source age checks (`PRICING_SOURCE_STALE_DAYS`).
5. **Administrative Governance & Violation Lifecycle**: Provides dedicated Admin REST endpoints (`/v1/admin/finops/pricing/*`, `/v1/budgets/*`, `/v1/budget-violations/*`) and web portals (`/dashboard/admin/finops/pricing`, `/dashboard/admin/finops/budgets`, `/dashboard/costs`) with role-based access control and manual pricing change log auditing.

## Model Pricing Seed Ingestion (`scripts/import_pricing_catalog.py`)

Operators can validate or ingest official rate card updates via the CLI:

```bash
# Validate seed syntax and calculate supersession diff without writing to database
python scripts/import_pricing_catalog.py --dry-run --file app/seeds/model_pricing_seed.yaml

# Apply the pricing update atomically and log the operator's identity
python scripts/import_pricing_catalog.py --apply --file app/seeds/model_pricing_seed.yaml --created-by "ops-team"
```

### Ingestion Semantics
- **Unchanged**: Rows matching active pricing records in keys, rates, units, and sources are skipped without modification.
- **Superseded**: When rates differ for an active model and token type, the existing row is marked inactive with `effective_to` set to now, and a new record referencing the old ID via `supersedes_pricing_id` is created.
- **Audit Logging**: An immutable batch report is recorded in `pricing_import_batches`, and individual diffs are saved to `pricing_change_logs`.
