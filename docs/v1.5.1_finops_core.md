# V1.5.1 Agent FinOps Core

本文是 V1.5.1 的 FinOps schema、官方價格 seed、Admin API 與 Dashboard 對照文件。V1.5.1 延續 V1.5 的成本帳本，但把 pricing、usage、cost、budget、violation 欄位補齊，並新增匯入批次、價格異動紀錄與官方來源文件 audit tables。

## 功能目標

- 完整記錄官方模型價格、用量、成本、預算與違規事件，讓 cost event 可以保留 pricing snapshot，不會因後續調價而改寫歷史成本。
- 支援 `app/seeds/model_pricing_seed.yaml` 官方價格 seed，提供 dry-run 驗證與 apply 匯入。
- 支援 Admin API 與 Dashboard 管理價格目錄、匯入報表、版本化異動與來源 audit。

## UI 與 Dashboard 驗證入口

| 入口 | 用途 |
| --- | --- |
| `/dashboard/admin/finops/pricing` | 查詢 Pricing Catalog，可用 provider、model、resource type、pricing mode、token type、scope 與 active only 篩選。 |
| `/dashboard/admin/finops/pricing/{pricing_id}` | 查看單筆價格完整欄位、有效期間、來源、能力旗標與 change log，也可做簡易價格編輯或停用。 |
| `/dashboard/admin/finops/pricing/import` | 輸入 seed 檔案路徑後執行 dry-run 或 apply，畫面會顯示 valid/new/unchanged/supersede/invalid 統計與完整 report JSON。 |
| `/dashboard/admin/finops/pricing/sources` | 查詢官方來源文件與 pricing change log。 |
| `/dashboard/costs` | 查詢 tenant cost summary、budget violations 與 pricing catalog 摘要。 |
| `/dashboard/runs/{run_id}` | 查詢單一 run 的 Cost Summary、usage events 與 cost events。 |

## Admin API

| Method | Path | 權限 | 用途 |
| --- | --- | --- | --- |
| `GET` | `/v1/admin/finops/pricing` | reviewer 以上 | 查詢 pricing catalog，支援 provider/model/resource/pricing/token/scope/active 篩選。 |
| `GET` | `/v1/admin/finops/pricing/{pricing_id}` | reviewer 以上 | 查詢單筆 pricing。 |
| `PATCH` | `/v1/admin/finops/pricing/{pricing_id}` | finops_admin 以上 | 更新單筆 pricing 管理欄位。 |
| `POST` | `/v1/admin/finops/pricing/{pricing_id}/disable` | finops_admin 以上 | 停用單筆 pricing。 |
| `POST` | `/v1/admin/finops/pricing/import/dry-run` | reviewer 以上 | 驗證 seed，計算 new/unchanged/supersede，不寫入資料庫。 |
| `POST` | `/v1/admin/finops/pricing/import/apply` | finops_admin 以上 | 匯入 seed，建立 import batch、source documents、pricing rows 與 change logs。 |
| `GET` | `/v1/admin/finops/pricing/imports` | reviewer 以上 | 查詢匯入批次。 |
| `GET` | `/v1/admin/finops/pricing/imports/{import_batch_id}` | reviewer 以上 | 查詢單一匯入批次。 |
| `GET` | `/v1/admin/finops/pricing/sources` | reviewer 以上 | 查詢官方來源文件 audit。 |
| `GET` | `/v1/admin/finops/pricing/changes` | reviewer 以上 | 查詢 pricing change log。 |

V1.5.1 新增 RBAC role：`super_admin`、`finops_admin`、`tenant_admin`、`reviewer`、`end_user`。FinOps reviewer 可查詢與 dry-run，FinOps admin 可 apply 匯入與停用價格。

## 官方價格 Seed 匯入

預設 seed 檔案：

```text
app/seeds/model_pricing_seed.yaml
```

CLI：

```bash
python scripts/import_pricing_catalog.py --dry-run --file app/seeds/model_pricing_seed.yaml
python scripts/import_pricing_catalog.py --apply --file app/seeds/model_pricing_seed.yaml --created-by release-manager
```

匯入邏輯：

- dry-run 只驗證 seed 與比對 DB，不建立 `pricing_import_batches`。
- apply 會建立 `pricing_import_batches`、`pricing_source_documents`、`pricing_change_logs`。
- 若 active pricing key 相同且價格、幣別、折扣、倍率、來源與 pricing version 都相同，列為 unchanged。
- 若 active pricing key 相同但價格或版本不同，舊 row 會設為 inactive 並填入 `effective_to`，新 row 會填入 `supersedes_pricing_id`。
- `cost_events.pricing_snapshot` 會保存計算當下的 pricing，不會被後續調價影響。
